1. Project Title
Student Task Manager
2. Problem Statement
Students often struggle with organizing academic tasks and deadlines.
This project helps users manage tasks using a simple desktop application.
3. Solution Overview
The application allows users to create, update, delete, and complete tasks.
All tasks are stored in a JSON file for persistence.
The application uses Object-Oriented Programming principles and modular architecture.
